# 🕵️ The Detective's Desk

An atmospheric Noir mystery investigative game built with modern serverless architecture, dual database resilience, real ambient audio, and full bilingual support (English & বাংলা).

## 🚀 Live Vercel Deployment Ready
- **Vercel Serverless API**: `/api/login`, `/api/register`, `/api/me`, `/api/logout`, `/api/score`, `/api/leaderboard`, `/api/demo`
- **Zero-Crash Database**: Works immediately out of the box with built-in storage, or connects to any cloud MySQL (TiDB, Supabase, Aiven, PlanetScale) via `MYSQL_URL`.
- **Noir Visual Design v2.0**: Dossier folder tabs, animated audio equalizer, forensic hotspots, Polaroid mugshots, corkboard evidence pins, and field notebook.

## 🛠️ Quick Local Start
```bash
npm install
npm start
```
Visit `http://localhost:3000` in your browser.
